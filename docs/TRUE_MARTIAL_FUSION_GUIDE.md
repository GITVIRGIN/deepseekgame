# 真武合流完整攻略

## 真武模式总目标

真武是隐藏最高难度。单流派硬打极难通关。核心目标：先建立双合流路线，再追求三合流终局爆发。

## 双合流路线形成规则

1. 前 4 层不会出现合流牌。
2. 5–6 层开始出现路线入口（入门）。
3. 拿到入门后，同一路线的后续组件才会出现。
4. 同路线牌越多，打法越完整：
   - 1 张：看到路线
   - 2 张：开始下注（押注）
   - 3 张：成型（formed）
   - 4–5 张：胡牌（highroll）
   - 6 张含大成牌：大成（mastered）

## 三合流触发规则

三合流不直接出现在普通奖励中。需要：
1. 某条双合流路线达到大成。
2. 楼层 ≥15。
3. 奖励中低概率出现天尊契机牌。
4. 选择契机牌后，不进牌组，直接获得三合流终局牌。

## 六条双合流路线

### 雷血（法术+流血）
- 核心：雷痕·灼烧·流血·自损·汲血
- 前期：拿法术启动与流血续航
- 中期：寻找雷血路线牌
- 后期：靠雷血爆发与回血稳住
- 失败原因：自损无续航、叠层不足

### 雷毒（法术+中毒）
- 核心：雷痕爆发+毒瘴持续
- 前期：优先上毒和雷法牌
- 中期：补毒层削弱
- 后期：靠雷法斩杀
- 失败原因：毒层不足、没补雷法

### 雷禁（法术+控制）
- 核心：雷法+离间·禁锢·眩晕
- 前期：拿控制窗口
- 中期：补伤害推进牌
- 后期：控场后爆发
- 失败原因：只堆控制无伤害、拖局

### 山岳（物理+龟壳）
- 核心：战意·直伤·格挡·反震
- 前期：保证格挡和直伤
- 中期：拿山岳路线牌
- 后期：高格挡反震+物理终结
- 失败原因：格挡不足、伤害跟不上

### 蚀血（流血+中毒）
- 核心：双持续伤害+汲血回血
- 前期：做出持续伤害密度
- 中期：补回血和保命
- 后期：双毒压血收割
- 失败原因：只拿自损牌无续航

### 玄狱（龟壳+控制）
- 核心：格挡·反震·离间·禁锢
- 前期：格挡+控制防守
- 中期：补终结伤害
- 后期：防守反击收尾
- 失败原因：只防守无终结、节奏过慢

## 选牌时间线

| 楼层 | 策略 |
|---|---|
| 1–4 | 纯单流派过渡 |
| 5–6 | 关注基础合流入口（入门） |
| 7–9 | 沿同一路线 commit（押注） |
| 10–14 | 争取 formed（成型） |
| 15+ | 寻找 highroll/mastered/天尊契机 |

## 推荐路线（新玩家）
**山岳（物理+龟壳）**：容错高，格挡+直伤最简单。

## 推荐路线（高阶追梦）
**蚀血（流血+中毒）→三灾雷血毒劫**：双持续→三灾→终局爆发。

## 真武预期胜率

- 整体通关率：~0.13%
- 三合流成型率：~0.31%
- 三合流胜率：~9.43%
- 真武是给后期玩家反复挑战的模式，失败是常态
