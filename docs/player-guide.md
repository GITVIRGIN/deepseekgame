# 《玄箓行》新手指南与进阶攻略

## 入门思路

刚开始游玩时，先把目标放在“活下来”。不要急着追求复杂连锁，也不要每次看到新方向就拿。一个能稳定运转的小核心，比一堆看起来很强但互相不配合的牌更可靠。

开局优先观察三件事：

- 当前牌组最容易打出的伤害来源是什么。
- 哪些回合最容易被敌人打穿。
- 奖励和商店里是否出现能补足短板的牌。

如果伤害足但容易掉血，先补格挡、回复或控制。如果能防住但打不死敌人，就补爆发、持续伤害或状态放大。

## 流派选择

流血、毒、雷、控制、防御和回复都可以成为核心，但它们的节奏不同。

流血和毒更适合持续压制，雷更适合爆发，控制适合争取时间，防御和回复负责提高容错。不要只问“哪张牌强”，更要问“它能不能让当前牌组更稳定”。

单流派更容易起步。双流派适合在中期补短板，例如毒配防御、雷配流血、控制配毒。三流派上限很高，但需要牌组已经比较稳定，不建议每局都强追。

## 奖励选择

奖励不是越多越好。牌组越厚，核心牌越难抽到。以下情况可以考虑放弃：

- 新牌不服务当前路线。
- 新牌费用太高，当前能量跟不上。
- 当前牌组已经需要删牌而不是加牌。
- 强卡会把路线带偏，让原本成型的组合变散。

## 商店与金币

金币要围绕当前问题使用。缺生存就找防御、回复或关键遗物；缺收尾就找爆发；核心牌太少就适当刷新。不要因为商店里出现稀有选项就立刻购买，先判断它是否真的解决问题。

删牌是商店中非常重要的成长方式。删除不再适配的基础牌或过时牌，可以提高核心牌出现的频率。

## 高压回合处理

高压回合先看敌人意图，再决定出牌顺序。不要只计算最大伤害，还要确认自己能不能活过敌人的回合。

如果手牌不顺，优先保住生命。控制牌、格挡牌和回复牌有时比输出更关键。很多失败并不是因为伤害不够，而是某一回合没有留出防御空间。

## 真武挑战

真武难度是高压挑战模式。它要求玩家理解流派合流、牌组厚度、资源规划和关键回合处理。失败是正常体验，真正重要的是复盘每一局为什么倒下。

建议先在普通难度熟悉卡牌、敌人和奖励，再进入真武难度。进入真武后，不要强行追求最华丽的终局路线。稳定成型的双流派，往往比过早分散的三流派更可靠。

## 常见失误

- 前期拿太多方向，导致牌组没有核心。
- 只追求伤害，忽视格挡和回复。
- 商店刷新过多，关键时刻没钱买真正需要的东西。
- 卡组太厚，核心牌迟迟不上手。
- 高难中只靠控制拖延，没有准备结束战斗的手段。
- 每局都强追三流派，错过了更稳定的双流派路线。
