# deepseekgame UI-R5 地图阶段背景参考包

用途：给 Codex 导入到 `D:\workspace\deepseekgame\UI` 保存，作为 UI-R5 后续替换“敌人死亡后暴露的占位背景 / 地图阶段背景”的美术基准。

## 包内容

- `reference_sheets/`
  - 已认可风格的阶段背景合集图。
- `runtime_candidates/`
  - 从 9 阶段合集裁出的 1920x1080 运行时候选背景。
  - 这些是候选稿，导入前仍需在游戏内截图确认是否有残留标签、边框或不适配裁切。
- `source_reference/`
  - 敌人死亡后空位背景风格参考图。
- `manifest.json`
  - 阶段名、文件名、导入目标与约束。

## 风格锁定

山西小西天壁画 / 彩塑 / 道教玄幻；暗底金线；暖橙红点缀；铜绿辅助。  
不要把“中心圆环”当成通用构图。只有悬空观台、阵台、天象异变等本来该有仪式圆形结构的场景才允许圆形元素。
